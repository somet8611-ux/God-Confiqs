چرا نصب آیفون هنوز آماده نیست؟

iOS امکان اجرای مستقیم این اسکریپت Node.js را مثل کامپیوتر فراهم نمی‌کند. نصب مرورگری به OAuth رسمی Cloudflare و پیش‌نیازهای انتشار آن نیاز دارد که هنوز تأیید نشده‌اند.

برای امنیت حساب، هیچ‌وقت از دوستان API Token نخواهیم و از آن‌ها نمی‌خواهیم رمز Cloudflare را در GOD CONFIQS وارد کنند.

نصب مستقل، بدون دامنه پولی

ساخت Worker و دیتابیس مستقیماً روی حساب Cloudflare خودت و با تأیید رسمی خودت انجام می‌شود. هیچ API Token یا رمز Cloudflare به این سایت ارسال نمی‌شود.

پس از نصب، کد یک‌بارمصرف ساخت مدیر در ترمینال نمایش داده می‌شود و در فایل محلی .bootstrap-code ذخیره می‌شود. آن را خصوصی نگه دار و پس از ساخت حساب مدیر حذف کن.

مراحل نصب

  1. Node.js نسخه ۲۰ یا جدیدتر را روی Windows، macOS یا Linux نصب کن.
  2. فایل نصب‌کننده را دانلود کن.
  3. دستور node god-confiqs-installer.mjs را اجرا کن.
  4. کد ورود رسمی Cloudflare را با گوشی یا کامپیوتر تأیید کن و مجوزهای نمایش‌داده‌شده را بررسی کن؛ اگر گسترده‌تر از حد قبول توست، لغو کن.
  5. حساب مقصد و ساخت منابع جدید را تأیید کن.
  6. نصب‌کننده D1، جدول‌ها، Binding و Worker جدید را می‌سازد و آدرس پنل را نمایش می‌دهد.

شفافیت مجوزهای Cloudflare

Wrangler OAuth Device Flow

ورود از مسیر رسمی Wrangler و تأیید مستقیم در Cloudflare انجام می‌شود. نصب‌کننده این پنج Scope معتبر Wrangler را درخواست می‌کند: account:read، user:read، workers:write، workers_scripts:write و d1:write؛ Wrangler برای تمدید ورود، offline_access را نیز خودکار اضافه می‌کند. این دسترسی‌ها به یک Worker یا دیتابیس خاص محدود نمی‌شوند. دو Scope مربوط به Workers می‌توانند دسترسی گسترده به منابع Workers حساب بدهند و d1:write امکان ساخت، تغییر و حذف دیتابیس‌های D1 حساب را می‌دهد. ساخت Worker جدید همچنان به نقش Admin در سطح محصول Workers نیاز دارد. نصب‌کننده فقط منابع جدید با نام تصادفی می‌سازد و هیچ دستور حذف یا بازنویسی منابع موجود اجرا نمی‌کند. کد نصب‌کننده فقط Worker و دیتابیس با نام‌های تصادفی جدید می‌سازد و هیچ دستور حذف یا بازنویسی منابع موجود را اجرا نمی‌کند. فهرست مجوزهای صفحه تأیید را بررسی کن و اگر Scope اضافی دیدی یا این سطح دسترسی را قبول نداری، لغو کن.

نکته فنی: دستور wrangler whoami نوع ورود و محل ذخیره امن اعتبارنامه را نشان می‌دهد، اما فهرست Scopeهای صادرشده را نمایش نمی‌دهد؛ بنابراین نصب‌کننده فقط OAuth و ذخیره رمزنگاری‌شده را بررسی می‌کند و صفحه تأیید Cloudflare مرجع نهایی مجوزهاست.

برای ساخت Worker جدید باید نقش Admin در سطح محصول Workers داشته باشی؛ برای ساخت دیتابیس D1 به d1:write و برای شناسایی حساب به account:read و user:read نیاز است. اطلاعات ورود با گزینه --use-keyring در مخزن امن سیستم‌عامل نگهداری می‌شود؛ هیچ API Token یا رمز Cloudflare به این سایت ارسال نمی‌شود. پس از نصب، در صورت تمایل می‌توانی با npx wrangler logout دسترسی محلی Wrangler را لغو کنی.

هر نصب نام Worker و دیتابیس یکتای خودش را می‌سازد و Workerهای قبلی را بازنویسی نمی‌کند. آدرس نهایی روی workers.dev رایگان خواهد بود.
